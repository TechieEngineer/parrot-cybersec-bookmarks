# Parrot OS Cybersecurity Bookmarks for Firefox 🦜

Default cybersecurity and pentesting bookmarks from Parrot OS Firefox profiles. Curated for security researchers, penetration testers, and enthusiasts who want a robust infosec infrastructure on any operating system.

## 📌 Features Included
* **Hacking Labs:** Hack The Box, VulnHub, PortSwigger, etc.
* **OSINT Services:** Shodan, Censys, IntelX, and tracking links.
* **Vulnerability Databases:** Exploit-DB, NVD, CVE Details.
* **Privacy & Security:** Tor Project, EFF, PrivacyTools.

---

## 🚀 How to Install in Firefox

### Method 1: The Quick UI Import (Recommended)

1. Click on the `parrot-bookmarks.html` file in this repository.
2. Click the **Download raw file** button (the down-arrow icon) to save it.
3. Open **Firefox**.
4. Press `Ctrl + Shift + O` (Windows/Linux) or `Cmd + Shift + O` (Mac) to open the **Library**.
5. Click the **Import and Backup** button (icon with two horizontal arrows).
6. Select **Import Bookmarks from HTML...**.
7. Choose the `parrot-bookmarks.html` file you just downloaded and click **Open**.

---

### Method 2: Download via Terminal (Linux/Mac)

Run this one-liner to download the bookmark file directly to your `Downloads` directory:

```bash
curl -Lo ~/Downloads/parrot-bookmarks.html https://githubusercontent.com
```
*(Note: Remember to manually import the file into Firefox using `Ctrl + Shift + O` after downloading!)*
